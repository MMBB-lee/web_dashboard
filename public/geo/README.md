# 安徽立体地图边界

`anhui-boundaries.json` 是当前地图使用的本地数据文件，随前端一起发布，无须运行时访问地图服务。旧的 `anhui.geojson` 占位文件不参与渲染。

来源：[阿里云 DataV.GeoAtlas](https://datav.aliyun.com/portal?tool=atlas)。于 2026-10-15 获取 `areas_v3/bound/340000_full.json` 和其中 16 个市对应的 `{市级 adcode}_full.json`。完整来源地址、下载时间和原文件 SHA-256 均保存在数据文件中。下载日期不代表边界测绘或行政区划生效日期，版本以来源文件为准。

- 包含 16 个地级市和 104 个区县。
- 区县原始坐标数组完整保留，共 35,421 个坐标点。
- `detailedCities` 与 `detailedProvince` 由同版本区县做拓扑合并得到，没有进行抽稀、平滑或坐标舍入；保留独立多边形与内部孔洞。
- `label_position` 是区域内部的名称锚点，用于放置文字，不是政府驻地或业务地点坐标。
- 坐标按 DataV 的 GCJ-02 口径使用。组件把边界与业务点位统一投影到墨卡托平面，立体底座高度仅为视觉效果。

更换数据时，应同时更换区县、市、省的几何与标签锚点，核对来源版本和坐标系，并运行 `pnpm test:map`。当前数据适用于项目可视化，保留源数据精度不等于测绘级精度保证。
