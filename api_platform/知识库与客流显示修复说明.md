## 知识库

原来只登记了文档，索引和分块都是 0。D 使用了 C 0.2.1 才提供的原文定位方法，但本机 C 是 0.2.0a2。
现在通过 C 现有仓储取得登记原件，校验文件路径、大小、SHA256 和文档版本后交给 E 建索引。
补充了已登记 HTML 的正文解析；PDF 中无法映射的字符以替换符标明，原件字节保持原样。
E 源码目录和本机虚拟环境中的解析模块均已更新。

登录管理员账号后，打开“智能问答”右上角“知识库管理”，可查看所有文档的状态、来源和有效期，上传 PDF/TXT/Markdown，或重建本页/单篇索引。
上传必须填标题、发布单位、来源、发布日期和使用权限说明。写请求保持管理员校验和 CSRF 校验。
后台 Worker 完成任务后才成为可检索资料；历史文档即使可检索，也不因此变成当前有效资料。

问候语有正常提示。自然语言客流提问可直接查询已核验的公开统计，支持“合肥机场”等名称。
“最近”显示库中最新可用统计期，并明确时间；没有实时数据时仍如实返回不足。
结构化指标查询保留完整周期校验，并适配 E 0.6.2 对失败结果字段的校验。
此功能不表示重新接通了此前被上游覆盖的大模型调用接线。

## 客流页面

景区资料主要是年、季和节假日统计，没有完整周/月序列。景区页现在按原始统计周期读取并绘制历史曲线；没有对应周/月序列时不生成预测。
交通页切换枢纽后按实际观测日期和粒度查询，避免用 2026 年范围查询只有 2025 年单日数据的车站。
景区和交通页保留原有图表布局，正式曲线仅展示已核验数据及其原始统计周期。原始统计与标准观测有重叠，不可相加。
单点曲线显示数据点；日、周轴保留完整日期。
