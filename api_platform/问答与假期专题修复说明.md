## 日期查询和流式回答（后续修复）

“今天日期”被错误送入知识库证据检索，因没有日期文档而显示“证据不足”。新增系统问答入口，日期、星期、当前时间及昨天/明天日期均由服务器时钟按北京时间 UTC+8 计算，不依赖文档或模型。真实客流问题仍执行原有的数据核验。

前端现在使用 `POST /api/v1/assistant/chat/stream`。后端按 `stream: true` 请求 OpenAI 兼容模型，通过 SSE 的 `start`、`delta`、`done` 事件逐段传递正文，完成后附带来源、统计查询和限制说明。日期、问候和直接核验出的简短数值即时返回，不添加人为打字延迟。原 `/assistant/chat` JSON 接口继续保留，演示模式继续使用原演示接口。

前端支持停止生成；中止时保留已生成文字并标记可能不完整。模型异常、超时或连接提前结束会显示错误及重试入口，不把部分内容标记为完成。停止或离开页面会取消浏览器请求，后端释放对应模型流连接。

验证：后端 36 项针对性测试、56 项问答/指标/知识库回归测试，前端 38 项测试、类型检查和生产构建通过；真实页面记录到 109 次中间文字更新，并验证日期回答和停止生成后保留部分文字。
