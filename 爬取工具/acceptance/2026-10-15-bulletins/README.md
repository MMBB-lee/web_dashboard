# 0.2.0 城市公报批次验收

本次只推进独立采集器第二步，不改 C/D/E 仓库、接口、作业或业务数据库。本批次离线使用已归档的官方 HTML，没有新增在线抓取，也没有声称来源网站当前仍可访问。

共17条：11条年度流量、6条12月31日年末存量。原260条机场月值逐条快照对比不变。当前共有277条标准事实、17个有数值对象；44对象中仍有27个未取得标准事实，不能宣称全省数据完整。

年度公报发布时间为2026年，统计期为2025年。发布日期与统计年份分别保存；标题和正文开头年份必须一致。年值不拆月，年末存量也不是12月31日游客流量。公报中的官方初步统计口径保留，不称为最终审定数。

## 可复核证据

- [SQLite摘要](./sqlite/summary.json)：首次新增17、重跑跳过277；77份受管理原件全部复核SHA。其中比76份迁入原件多的一份来自此前机场在线目录采集。库中保留1条先前失败记录，本批次无新增失败或冲突。
- [MySQL摘要](./mysql/summary.json)：MySQL8.4.11、8张独立表、76原件、277事实、0修订、0问题；首次新增17，重跑跳过277。
- 两套目录的 `first.json`、`repeat.json` 保留逐资产状态；26份尚未适配样本继续仅归档，未宣称数值解析完成。
- [新增事实与定位](./mysql/city-facts.json)：17条均通过源文件SHA、XPath唯一命中、原文段落和匹配值复查；每条保存来源URL、发布日期、单位换算及范围。
- [覆盖报告](./mysql/coverage.json)：明确区分年度流量、年末存量、机场月值和没有数值的对象，不补零。

`scripts/verify_city_batch.py` 可在独立库或新SQLite复核本批次；内含人工对照原件后固定的17个预期值，不从解析输出自动生成预期值。离线合成测试另覆盖单位变化、约数、预测、重复正文、表格/导航污染、错误年份、摘要/日期不一致及单份公报整批拒绝。

最终源码与安装wheel分别85项测试全部通过，见 `source-tests.xml` 和 `installed-wheel-tests.xml`。最终安装包再次通过[SQLite复核](./installed-wheel-sqlite/summary.json)、[MySQL复核](./installed-wheel-mysql/summary.json)和[脱离工程目录的首次/重复入库](./portable/summary.json)。包内11份代码/配置与安装结果逐字节一致，环境不含团队模块。MySQL验收后已关闭，文件保留；综合状态见[发布复核](./release-verification.json)。
