# 本机爬虫实时控制台

控制台访问地址：**http://127.0.0.1:8765**。仅在本机访问，浏览器每15秒读取一次当前数据库；不会因为刷新页面而触发采集。

## 打开与关闭

Mac双击工程根目录的 **打开爬虫控制台.command**，保持打开的终端窗口运行。脚本使用Python 3标准库，不需要安装前端依赖，也不依赖团队服务。

也可从独立爬虫工程目录执行：

```bash
python3 scripts/dashboard.py --open
```

默认读取日常库：`~/Library/Application Support/AnhuiPublicDataCrawler/data/crawler.sqlite3`。开发库`data/local`与日常库是不同副本，如要指定其他采集目录：

```bash
python3 scripts/dashboard.py --data-root './data/local' --port 8766 --open
```

Windows使用相同Python入口，必须通过`--data-root`指定本机已有SQLite采集目录；当前页面已在Mac实测，未据此宣称Windows实机验收通过。控制台暂不连接MySQL。

服务仅监听127.0.0.1；终端按Ctrl+C停止。若8765已占用，可访问已启动的页面或指定其他端口。终端关闭或电脑重启后需要重新启动；本次未给控制台另装后台定时任务。

## 页面内容

| 页面 | 实际数据与操作 |
|---|---|
| 运行总览 | 标准/候选事实数量、原件数、对象有值率、最近更新异常、单机场月值趋势和最近运行 |
| 来源监控 | 启用状态、当前源状态、待处理和待审数量、最近检查/成功/下次到期、失败原文及来源链接 |
| 采集结果 | 按名称、类型、指标、质量和区间筛选；分页；导出当前筛选CSV/JSON；查看公开原文、完整SHA256、定位及换算说明 |
| 运行日志 | 最近100次真实运行的状态、开始/结束时间、新增/去重/修订/隔离及逐URL结果 |
| 覆盖与缺口 | 8机场自2023年起的原生月值矩阵、44个对象的标准/候选数量 |

总览与其他非结果页的“导出数据”导出全部标准事实；结果页导出当前筛选，候选限定语保留。日期筛选按统计区间相交，不裁剪年度、假期或累计周期。不同指标与单位不混合求和，机场缺月不补零、不插值。

## 状态口径

- “已连接·只读”表示控制台成功读取数据库，不代表爬虫正在运行，也不代表所有来源正常。
- “当前空闲”依据库内没有running任务；若存在运行标记，页面明确提示结合日志确认，不把遗留标记当作已确认存活的进程。
- “最近更新异常”来自最近一个完整更新报告；“来源监控”显示各源持久化状态，两个统计范围不同。
- “下次到期”表示来源可再次检查的时间，不是系统保证执行的时刻；现有日常采集任务仍负责触发。
- 对象有值率只说明某对象有至少一条标准事实，不等于所有年份、全部指标或完整性验收通过。
- 数据库不可读时显示连接失败并保留上次成功读取的数据，不展示伪造的0或成功状态。

读取接口`GET /api/dashboard`使用SQLite `mode=ro`、`query_only=ON`及单个读取事务；不初始化、不迁移、不写任务或业务数据，不暴露任意文件访问入口。页面静态文件及图表均在本机，不使用外部CDN。

## 本轮验证

源码回归共137项通过（原127项及控制台10项）。控制台专项检查覆盖只读不改变数据库、缺库不创建、拒绝外来表、未写完更新报告的回退、URL与运行明细字段投影。

浏览器实测五个视图切换、来源搜索、质量筛选、证据弹窗、运行状态筛选及CSV下载；导出的2条候选保留“约/超过”。1440px桌面与415px窄屏均无页面级横向溢出，浏览器未记录脚本错误。测试与截图在[本轮控制台证据目录](../acceptance/2026-10-17-dashboard/README.md)。
